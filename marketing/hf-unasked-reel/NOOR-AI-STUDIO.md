# Noor in Google AI Studio: everything for this reel in one place

Open **AI Studio → Generate speech** and fill in each field below. The profile fields (Audio Profile, Scene) are the
same as in every reel, so Noor stays the same person (`../voice-studio/README.md`). Style and Sample Context are set
for this reel.

## Settings

- **Model:** `gemini-3.1-flash-tts-preview` (if it isn't listed: `gemini-2.5-pro-preview-tts`)
- **Voice:** `Leda`
- **Style:** `Vocal Smile`
- **Pace:** `Natural`
- **Accent:** `Iraqi Arabic (Baghdadi)`

## Audio Profile

```
"Noor", the narrator of the @allawi.psd reels: a 25-year-old woman from Baghdad.
She speaks Iraqi Arabic, Baghdadi dialect only. Never Modern Standard Arabic, never Gulf, Levantine or Egyptian.
```
