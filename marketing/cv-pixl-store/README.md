# CV for the Pixl Store social media job

One A4 page in Arabic, set in Markazi Text (Google Fonts, SIL Open Font License), a text face drawn for reading
Arabic in print.

- `cv.html` is the page; `node render.cjs` writes `out/Ali-Ahmed-Shihab-CV.pdf` and a PNG for Instagram DMs.
- `python3 tidy.py` then sets the PDF's author and title and strips the PNG down to its pixels.
