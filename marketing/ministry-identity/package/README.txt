01-Presentation

02-Concept
  Concept.pdf / Concept.txt        شرح فكرة الشعار ودلالات عناصره وألوانه

03-Logo
  SVG   الرمز بصيغة متجهة، للفتح في Illustrator وغيره
  PDF   كل نسخ الشعار بصيغة متجهة
  PNG   كل نسخ الشعار بخلفية شفافة وبدقة عالية
        mark-color                 الرمز بالألوان، للخلفيات الفاتحة
        mark-color-on-dark         الرمز بالألوان، للخلفيات الداكنة
        mark-black / mark-white    الرمز بلون واحد، للأختام والطباعة
        lockup-horizontal          الصيغة الأفقية مع اسم الوزارة، ونسختاها للخلفيات الداكنة وبلون واحد
        lockup-vertical            الصيغة العمودية، ونسختها للخلفيات الداكنة
