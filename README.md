# viZion

The viZion course site: an Iraqi e-commerce course written as a website, with the chapters, the solutions,
the Iraq guide, the dinar calculators and the advisor. Live at https://vizioniq.vercel.app

## Run it

1. `npm install`
2. Copy `.env.example` to `.env.local` and put the advisor's API key in it
3. `npm run dev`, then open http://localhost:3000

Pushing to `main` deploys on Vercel.
